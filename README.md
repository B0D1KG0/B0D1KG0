## 🌆 BebraGrad

[**BebraGrad**](https://github.com/BebraGrad) is a virtual city in Minecraft with its own ecosystem of apps:

| Project | What it is | Stack |
|---|---|---|
| WebSite | Main website of the city | PHP, CSS, JS |
| WebSite-AdmMenu | Admin panel for the website | PHP |
| WebSocket-Chat | Real-time chat | JS |
| DiscordBot | Discord bot for the community | Python |
| TelegramBot | Telegram notifications bot | Python |
| MinecraftLink | Links the game server with the other services | Java |
| MinecraftTimetracker | Tracks players' time on the server | Java |
